# SignApp
Приложение имитирует регистрацию пользователя в приложении и позволяет менять данные этого профиля.

## Стэк
+ Xcode
+ Swift
+ MVC
+ UIKit
+ Storyboard
+ Auto Layout

## Цели и задачи
+ изучение передачи данных между экранами, размещенными не последовательно
+ практика командной разработки
+ работа с большим количеством view controller, переходов и состояний
+ отработка свойств и методов элементов UI
+ разработка хорошего UX
